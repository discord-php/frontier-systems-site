# Frontier Systems marketing site

- This repository hosts the public marketing website, not the simulation or PHP runtime.
- Source lives in `site/`; `tools/build.mjs` generates `dist/`. Never edit generated HTML.
- Run `npm run build` and `npm run check`. Preview with `npm run serve` on loopback port 4186; verify desktop and mobile layouts.
- Target `main` via an open PR. The website workflow validates PRs and publishes only main. Preserve the separate DiscordPHP.org site and DNS records.
- Keep current gameplay verification captures internal. Original MIT schematic branding is allowed; label conceptual illustrations accurately.
- Funding contributions are not preorders or game-key sales. Enable a storefront only with an owner-approved URL, price/offer description and reviewed availability. No fabricated launch date or live funding total.
- Preserve static Discord component previews plus Open Graph fallback. No tokens, bots, custom_id or interactive callbacks in website previews.
- New access, secrets, paid services or required human approvals go through the Coordinator chat.
